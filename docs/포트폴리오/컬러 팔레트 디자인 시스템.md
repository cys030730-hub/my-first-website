## 컬러 사용 가이드

### Primary — `--color-primary` (#C5D96B)
- 페이지 배경(지형/언덕), 대형 섹션 배경, 히어로 영역 등 화면의 가장 넓은 면적을 차지하는 곳에 사용
- 브랜드를 대표하는 색이므로 로고 배경, 섹션 디바이더에도 활용 가능
- 명도가 밝아 어두운 텍스트(`--color-text-primary`)와 대비를 이루어야 가독성이 확보됨

### Secondary — `--color-secondary` (#2F5233)
- 나무·식생 등 디테일 일러스트 요소, 푸터 배경, 강조 카드의 배경색으로 사용
- Primary와 함께 쓰였을 때 "자연/야외" 컨셉을 유지하는 역할
- 텍스트에 사용할 경우 밝은 배경 위에서만 사용 (명도 대비 확보)

### Accent — `--color-accent` (#E8A33D)
- CTA(Call To Action) 버튼, 호버 상태, 알림 배지 등 사용자의 시선을 반드시 끌어야 하는 요소에 제한적으로 사용
- 전체 팔레트에서 유일한 난색 계열이므로 과용 시 임팩트가 사라짐 — 페이지당 1~2곳 이내 권장
- 링크 호버, 아이콘 강조, 포인트 일러스트(캐릭터 등)에 적합

### Background
- `--color-bg-primary` (#F7F8F2): 콘텐츠 영역, 카드, 모달 등 텍스트 가독성이 중요한 곳의 기본 배경
- `--color-bg-secondary` (#C5D96B): 히어로/풀블리드 섹션 배경
- `--color-bg-sky` (#A8C8E8): 보조 섹션(소개, 갤러리 등) 배경으로 청량감을 줄 때 사용

### Text Colors
- `--color-text-primary` (#1A1A1A): 헤드라인, 제목 등 가장 강한 강조가 필요한 텍스트
- `--color-text-secondary` (#4A4A4A): 본문, 서브카피
- `--color-text-muted` (#2C2C2C): 네비게이션, 캡션, 저작권 표기 등 부차적 텍스트

### Border / Outline
- 모든 일러스트 오브젝트와 버튼에 `--color-border` (#1A1A1A)로 두꺼운 아웃라인을 적용해 플랫 일러스트 스타일 유지
- 카드/입력창 등 UI 요소는 `--color-border-light` (#2C2C2C)로 한 단계 부드럽게 처리 가능

### Interactive (버튼/링크)
- 기본 버튼: 배경 `--color-button-primary`(흰색) + 테두리·텍스트 `--color-border`
- 버튼 호버: 배경 `--color-button-hover`로 미세하게 톤다운, 또는 테두리를 `--color-accent`로 전환해 피드백 강조
- 링크: 기본 상태는 `--color-link`(텍스트와 동일 톤), 호버 시 `--color-link-hover`(accent)로 전환하여 인터랙션을 명확히 표시

## 반응형 고려사항

### 다크모드
현재 팔레트는 라이트 테마 기준으로 채도가 낮은 파스텔 톤이라, 다크모드 적용 시 단순 반전이 아닌 별도 매핑이 필요합니다.

```css
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg-primary: #1E2320;
    --color-bg-secondary: #2A3B28;
    --color-text-primary: #F7F8F2;
    --color-text-secondary: #C8CFC2;
    --color-text-muted: #9AA396;
    --color-border: #F7F8F2;
    --color-button-primary: #2A3B28;
    --color-button-hover: #33452F;
    --color-accent: #F2B25A; /* 다크 배경에서 시인성 확보를 위해 약간 밝게 조정 */
  }
}
```
- Primary(#C5D96B)와 Accent(#E8A33D)는 다크 배경에서도 채도를 유지하되, 배경/텍스트 색상만 반전시켜 브랜드 정체성을 유지
- 순수 블랙(#000000) 대신 다크 그린 계열 배경(#1E2320)을 사용해 자연 컨셉과의 일관성 유지

### 화면 크기별 고려사항
- 모바일에서는 넓은 색면(Primary 배경) 대비 텍스트 대비율이 더 중요하므로, 작은 화면일수록 `--color-text-primary`를 배경 위에 직접 얹기보다 `--color-bg-primary` 카드로 감싸는 것을 권장
- 아웃라인이 두꺼운 일러스트 스타일 특성상, 저해상도/작은 화면에서는 테두리 두께를 줄여도 색상 대비는 유지되도록 설계

### 접근성(A11y)
- `--color-text-secondary` (#4A4A4A) on `--color-bg-primary` (#F7F8F2): 명도 대비 약 8.2:1 → WCAG AA/AAA 통과
- `--color-text-primary` (#1A1A1A) on `--color-primary` (#C5D96B): 명도 대비 약 9.5:1 → WCAG AA/AAA 통과
- `--color-accent` (#E8A33D)를 텍스트 색상으로 사용할 경우 반드시 어두운 배경 또는 `--color-text-primary`와 조합하여 대비 기준(4.5:1 이상)을 확보할 것
