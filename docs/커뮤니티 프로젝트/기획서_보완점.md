# 기획서 보완점

> 대상 문서: `docs/커뮤니티 프로젝트/기획서.txt` (FIND YOUR SKKIN)

## 1. 기획의 근본 방향 — 가장 먼저 정리 필요
- **"커뮤니티"인지 "브랜드 공식몰"인지 모호**: 참고 사이트가 "아이오페 공식몰"인데, 기획서에서는 "스킨케어 브랜드"를 주제로 한 커뮤니티라고 되어 있음. 브랜드 공식몰(제품 판매 중심)과 커뮤니티(정보/후기 공유 중심)는 페이지 구조와 기능이 완전히 다름. **"자체 브랜드가 있고 그 브랜드의 제품 후기 커뮤니티"인지, "여러 스킨케어 제품을 리뷰하는 오픈 커뮤니티"인지** 먼저 확정 필요.
- **타겟 사용자 정의 없음**: "young한 느낌"이라고만 되어 있고 실제 타겟(연령대, 피부고민 유형 등)이 없음. 이게 있어야 카피, 기능 우선순위가 잡힘.

## 2. 정보구조(IA) 누락
- 제품/게시글을 **분류할 카테고리**가 없음 (피부타입별: 지성/건성/복합성, 고민별: 트러블/미백/주름, 제품 카테고리별: 스킨/로션/크림/선크림 등).
- **검색 기능**이 명세에 없음. 리뷰 커뮤니티는 검색이 핵심 기능인데 빠져있음.
- 게시물 목록에 **정렬/필터**(최신순, 좋아요순, 별점순) 언급이 없음.

## 3. 페이지 흐름에 빠진 단계
- **게시글 작성/수정/삭제 페이지**가 명세에 없음 (목록·상세만 있음).
- **마이페이지**가 없음: 내가 쓴 글, 내가 좋아요 누른 글, 프로필 수정, 비밀번호 변경, 회원탈퇴.
- **회원가입 완료 후 이메일 인증** 절차 여부가 불명확함.

## 4. "댓글 기능"과 "후기" 구조가 혼재
- "댓글 기능" 항목이 실제로는 별점+후기 형태라, 게시물 상세에서 말한 "후기 정보"와 무엇이 다른지 겹침. **게시글=하나의 리뷰 글인지, 게시글 밑에 여러 사람이 각자 별점을 매기는 후기(댓글)를 다는 구조인지** 명확히 나눠야 함. 후자라면 "게시글 자체 별점"과 "댓글 별점"이 따로 존재하는 건지도 정해야 함.

## 5. 개인정보 수집 관련 (중요)
- 회원가입 시 **전화번호, 거주 국가**까지 수집하는데, 왜 필요한지 목적이 없고 **개인정보처리방침 동의, 이용약관 동의 체크박스**가 빠져 있음. 실서비스라면 법적으로 필수.
- 특히 커뮤니티 서비스에서 전화번호를 왜 받는지 재검토 필요 (본인인증용이 아니라면 불필요한 수집일 수 있음).

## 6. 커뮤니티 운영에 필수적인 기능 누락
- **신고/차단 기능**: 악성 댓글, 부적절한 게시글 신고 기능이 없음. 커뮤니티라면 필수.
- **알림 기능**: 내 글에 댓글/좋아요가 달렸을 때 알림 여부.
- **관리자(운영자) 페이지**: 신고 처리, 게시글/회원 관리 화면 언급이 전혀 없음.

## 7. 구체화가 필요한 기능들
- **별점**: 5점 척도인지, 보습력/자극도/향 등 세부 항목별 평점인지.
- **좋아요**: 1인당 중복 클릭 방지 로직 필요 여부.
- **사진 업로드**: 몇 장까지, 용량 제한, 리사이징 여부.

## 8. 기술 스택/인증 방식 확정 필요
- Supabase 사용 예정으로 보이는데, **이메일/비밀번호 방식만 쓸지, 소셜 로그인(구글/카카오 등)도 추가할지** 기획서에 명시하면 좋음. young 타겟이라면 카카오/구글 로그인이 이탈률을 크게 줄임.

## 9. 디자인 관련
- 색상 테마 "초록계열 자연친화적 톤"은 `docs/포트폴리오/컬러 팔레트 디자인 시스템.md`와 결이 비슷한데, 이 프로젝트 전용 팔레트를 별도로 정의할지 확인 필요.
