== FIND YOUR SKKIN DB 구조 기획서 ==

참고 문서: 기획서.md (공식몰 + 리뷰 커뮤니티)
DB: Supabase (PostgreSQL)
테이블 네이밍 규칙: 모든 테이블명 앞에 'FYS_' 접두어 사용

--------------------------------------------------
1. 테이블 개요
--------------------------------------------------
- FYS_profiles           : 회원 프로필 (Supabase auth.users 확장)
- FYS_products            : 제품 정보 (공식몰)
- FYS_product_skin_types  : 제품-피부타입 매핑 (다대다)
- FYS_product_concerns    : 제품-피부고민 매핑 (다대다)
- FYS_reviews             : 리뷰 게시글 (커뮤니티)
- FYS_review_images       : 리뷰 첨부 이미지 (최대 5장)
- FYS_review_likes        : 리뷰 좋아요 (중복 방지)
- FYS_comments            : 댓글/대댓글
- FYS_comment_likes       : 댓글 좋아요 (중복 방지)
- FYS_reports             : 신고 내역
- FYS_notifications       : 알림

--------------------------------------------------
2. ENUM 타입 정의
--------------------------------------------------
skin_type_enum      : 지성 / 건성 / 복합성 / 민감성
concern_enum         : 트러블 / 미백 / 주름 / 모공 / 수분
product_type_enum    : 스킨 / 로션 / 크림 / 선크림 / 클렌저 / 에센스
report_target_enum   : review / comment
report_status_enum   : pending / reviewed / rejected
notification_type_enum : like / comment / reply / report_result
user_role_enum       : user / admin

--------------------------------------------------
3. 테이블 상세 정의
--------------------------------------------------

[FYS_profiles] — 회원 프로필
- id              uuid            PK, FK → auth.users.id
- nickname        text            NOT NULL, UNIQUE
- role            user_role_enum  NOT NULL, DEFAULT 'user'
- created_at      timestamptz     NOT NULL, DEFAULT now()
- updated_at      timestamptz     NOT NULL, DEFAULT now()
비고: 이메일/비밀번호는 Supabase auth.users가 관리. 전화번호/거주국가는 기획서 보완에 따라 수집하지 않음.

[FYS_products] — 제품 (공식몰)
- id              uuid            PK, DEFAULT gen_random_uuid()
- name            text            NOT NULL
- price           integer         NOT NULL
- description     text
- image_url       text
- product_type    product_type_enum  NOT NULL
- avg_rating      numeric(2,1)    DEFAULT 0        -- 리뷰 집계 캐시
- review_count    integer         DEFAULT 0        -- 리뷰 집계 캐시
- created_at      timestamptz     NOT NULL, DEFAULT now()
- updated_at      timestamptz     NOT NULL, DEFAULT now()

[FYS_product_skin_types] — 제품 ↔ 피부타입 (다대다)
- product_id      uuid            FK → FYS_products.id, ON DELETE CASCADE
- skin_type       skin_type_enum  NOT NULL
PK (product_id, skin_type)

[FYS_product_concerns] — 제품 ↔ 피부고민 (다대다)
- product_id      uuid            FK → FYS_products.id, ON DELETE CASCADE
- concern         concern_enum    NOT NULL
PK (product_id, concern)

[FYS_reviews] — 리뷰 게시글
- id              uuid            PK, DEFAULT gen_random_uuid()
- product_id      uuid            FK → FYS_products.id, ON DELETE CASCADE
- user_id         uuid            FK → FYS_profiles.id, ON DELETE CASCADE
- title           text            NOT NULL
- content         text            NOT NULL
- rating          smallint        NOT NULL, CHECK (rating BETWEEN 1 AND 5)
- like_count       integer         DEFAULT 0        -- FYS_review_likes 집계 캐시
- comment_count    integer         DEFAULT 0        -- FYS_comments 집계 캐시
- created_at      timestamptz     NOT NULL, DEFAULT now()
- updated_at      timestamptz     NOT NULL, DEFAULT now()
인덱스: (product_id), (user_id), (created_at DESC), (rating), (like_count DESC)  -- 정렬/필터 대응

[FYS_review_images] — 리뷰 첨부 이미지
- id              uuid            PK, DEFAULT gen_random_uuid()
- review_id       uuid            FK → FYS_reviews.id, ON DELETE CASCADE
- image_url       text            NOT NULL
- sort_order      smallint        NOT NULL, DEFAULT 0
제약: 리뷰당 최대 5장 (애플리케이션 레벨 검증 + 트리거 권장)

[FYS_review_likes] — 리뷰 좋아요
- id              uuid            PK, DEFAULT gen_random_uuid()
- review_id       uuid            FK → FYS_reviews.id, ON DELETE CASCADE
- user_id         uuid            FK → FYS_profiles.id, ON DELETE CASCADE
- created_at      timestamptz     NOT NULL, DEFAULT now()
UNIQUE (review_id, user_id)   -- 중복 좋아요 방지

[FYS_comments] — 댓글 / 대댓글
- id              uuid            PK, DEFAULT gen_random_uuid()
- review_id       uuid            FK → FYS_reviews.id, ON DELETE CASCADE
- user_id         uuid            FK → FYS_profiles.id, ON DELETE CASCADE
- parent_comment_id uuid          FK → FYS_comments.id, ON DELETE CASCADE, NULL 허용 (NULL = 최상위 댓글, NOT NULL = 대댓글)
- content         text            NOT NULL
- like_count       integer         DEFAULT 0        -- FYS_comment_likes 집계 캐시
- created_at      timestamptz     NOT NULL, DEFAULT now()
- updated_at      timestamptz     NOT NULL, DEFAULT now()
인덱스: (review_id), (parent_comment_id)

[FYS_comment_likes] — 댓글 좋아요
- id              uuid            PK, DEFAULT gen_random_uuid()
- comment_id      uuid            FK → FYS_comments.id, ON DELETE CASCADE
- user_id         uuid            FK → FYS_profiles.id, ON DELETE CASCADE
- created_at      timestamptz     NOT NULL, DEFAULT now()
UNIQUE (comment_id, user_id)

[FYS_reports] — 신고
- id              uuid            PK, DEFAULT gen_random_uuid()
- target_type     report_target_enum  NOT NULL   -- review / comment
- target_id       uuid            NOT NULL        -- FYS_reviews.id 또는 FYS_comments.id (폴리모픽, FK 제약 없음)
- reporter_id     uuid            FK → FYS_profiles.id, ON DELETE CASCADE
- reason          text            NOT NULL
- status          report_status_enum  NOT NULL, DEFAULT 'pending'
- created_at      timestamptz     NOT NULL, DEFAULT now()
- resolved_at     timestamptz
인덱스: (status), (target_type, target_id)

[FYS_notifications] — 알림
- id              uuid            PK, DEFAULT gen_random_uuid()
- user_id         uuid            FK → FYS_profiles.id, ON DELETE CASCADE   -- 알림 수신자
- type            notification_type_enum  NOT NULL
- actor_id        uuid            FK → FYS_profiles.id                     -- 알림 발생시킨 사용자
- review_id       uuid            FK → FYS_reviews.id, ON DELETE CASCADE, NULL 허용
- comment_id      uuid            FK → FYS_comments.id, ON DELETE CASCADE, NULL 허용
- is_read         boolean         NOT NULL, DEFAULT false
- created_at      timestamptz     NOT NULL, DEFAULT now()
인덱스: (user_id, is_read), (created_at DESC)

--------------------------------------------------
4. 테이블 관계 요약 (ERD 설명)
--------------------------------------------------
FYS_profiles 1 --- N FYS_products는 관계 없음 (제품은 브랜드 소유, 작성자 없음)
FYS_profiles 1 --- N FYS_reviews
FYS_profiles 1 --- N FYS_comments
FYS_profiles 1 --- N FYS_review_likes / FYS_comment_likes / FYS_reports / FYS_notifications

FYS_products 1 --- N FYS_reviews
FYS_products N --- N skin_type_enum  (FYS_product_skin_types 경유)
FYS_products N --- N concern_enum    (FYS_product_concerns 경유)

FYS_reviews 1 --- N FYS_review_images
FYS_reviews 1 --- N FYS_review_likes
FYS_reviews 1 --- N FYS_comments
FYS_reviews 1 --- N FYS_notifications (review_id)

FYS_comments 1 --- N FYS_comments (self-reference, parent_comment_id) → 대댓글
FYS_comments 1 --- N FYS_comment_likes

FYS_reports.target_id → FYS_reviews.id 또는 FYS_comments.id (target_type으로 구분되는 폴리모픽 참조, DB 레벨 FK 제약은 걸 수 없어 애플리케이션에서 무결성 검증)

--------------------------------------------------
5. 집계값(캐시 컬럼) 처리 방식
--------------------------------------------------
- FYS_products.avg_rating / review_count
- FYS_reviews.like_count / comment_count
- FYS_comments.like_count
위 컬럼들은 조회 성능을 위한 비정규화 캐시값으로,
Supabase의 DB 트리거(AFTER INSERT/DELETE) 또는 Edge Function으로
FYS_review_likes/FYS_comments/FYS_reviews 테이블 변경 시 자동 갱신 필요.

--------------------------------------------------
6. RLS(Row Level Security) 정책 가이드
--------------------------------------------------
- FYS_profiles       : 본인 행만 UPDATE 가능, SELECT는 전체 공개
- FYS_products       : SELECT 전체 공개, INSERT/UPDATE/DELETE는 admin만
- FYS_reviews        : SELECT 전체 공개, INSERT는 로그인 사용자, UPDATE/DELETE는 작성자 본인 또는 admin
- FYS_comments       : FYS_reviews와 동일 정책
- FYS_review_likes / FYS_comment_likes : INSERT/DELETE는 본인(user_id = auth.uid())만
- FYS_reports        : INSERT는 로그인 사용자, SELECT/UPDATE는 admin만
- FYS_notifications  : SELECT/UPDATE(읽음 처리)는 본인(user_id = auth.uid())만

--------------------------------------------------
7. 향후 검토 사항
--------------------------------------------------
- 소셜 로그인 도입 시 FYS_profiles와 auth.identities 연동 확인 필요
- 리뷰 이미지 저장은 Supabase Storage 버킷 사용, FYS_review_images.image_url에는 Storage 경로 저장
- 제품 검색(리뷰 검색 포함) 고도화 시 PostgreSQL Full Text Search(tsvector) 컬럼 추가 검토
