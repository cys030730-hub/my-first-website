# 나만의 커뮤니티 기획서

## 서비스 구조
- 스킨케어 브랜드 공식몰(제품 소개/판매)
- 해당 브랜드 제품을 리뷰하는 오픈 커뮤니티(공식몰과 별도 메뉴/창으로 진입)

## 커뮤니티 주제
- 스킨케어 브랜드 공식몰 + 브랜드 제품 리뷰 커뮤니티

## 디자인 스타일
- **사이트 이름**: FIND YOUR SKKIN
- **색상 테마**: 초록계열의 자연친화적 톤
- **분위기**: 심플하고 여백이 많음 (다만 young한 타겟을 노리는 브랜드이기에, 톤은 차분하되 포인트 컬러나 폰트에서 young한 느낌이 들어야 함)
- **타겟**: 스킨케어에 관심 많은 2030 여성/남성 (추후 구체화 필요)

## 제품 카테고리 분류
- **피부타입별**: 지성 / 건성 / 복합성 / 민감성
- **피부고민별**: 트러블 / 미백 / 주름 / 모공 / 수분
- **제품 카테고리별**: 스킨(토너) / 로션 / 크림 / 선크림 / 클렌저 / 에센스

## 특별한 기능 아이디어
- 좋아요, 별점(5점 척도)
- 리뷰 검색 기능
- 리뷰 목록 정렬/필터: 최신순 / 좋아요순 / 별점 높은순 / 카테고리(피부타입·고민·제품유형)별 필터
- 신고 기능(부적절한 게시글/댓글)
- 알림 기능(내 글에 댓글/좋아요 발생 시)

## 페이지별 특징

### 공식몰
- **제품 목록 페이지**: 제품 카드(썸네일, 제품명, 가격, 카테고리 태그), 카테고리별 필터(피부타입/고민/제품유형)
- **제품 상세 페이지**: 제품 이미지, 제품명, 가격, 상세 설명, 해당 제품의 커뮤니티 리뷰 요약(평균 별점, 리뷰 수) 및 리뷰 게시판 바로가기

### 계정
- **로그인 페이지**: 이메일(계정) 입력 / 패스워드(마스킹 처리) / 로그인 버튼 / 회원가입 버튼 / 비밀번호 찾기 버튼
- **회원가입 페이지**: 이메일(계정) / 패스워드(마스킹 처리) / 패스워드 확인(오타 검증용) / 닉네임 / 이용약관 및 개인정보처리방침 동의(필수 체크박스)
  - 전화번호, 거주 국가 항목은 필수 목적이 불명확하여 제외(추후 본인인증이나 해외배송 등 명확한 사유가 생기면 재검토)
- **마이페이지**: 내가 쓴 리뷰 목록, 내가 좋아요 누른 리뷰 목록, 프로필(닉네임) 수정, 비밀번호 변경, 회원탈퇴

### 리뷰 커뮤니티
- **게시물(리뷰) 목록 페이지**: 리뷰 카드(제품명, 리뷰 제목, 작성자, 작성 날짜, 별점, 좋아요 수, 댓글 수, 대표 이미지), 카테고리 필터 + 정렬(최신순/좋아요순/별점순) + 검색창
- **게시물(리뷰) 작성/수정 페이지**: 대상 제품 선택, 별점(5점 척도), 리뷰 제목, 본문, 사진 업로드(최대 5장, 장당 5MB 이하)
- **게시물(리뷰) 상세 페이지**: 대상 제품 정보, 리뷰 제목/작성자/작성 날짜, 별점, 본문, 좋아요 버튼 + 좋아요 수(중복 클릭 방지), 신고 버튼
- **댓글 기능**: 댓글 작성자 닉네임, 작성 시간, 댓글 내용, 댓글 좋아요, 대댓글, 댓글 신고

### 운영
- **관리자 페이지**: 신고 접수 목록 및 처리, 게시글/댓글/회원 관리

## 인증 방식
- 이메일/비밀번호 기본 인증(Supabase Auth)
- 소셜 로그인(구글/카카오) 추가 여부는 추후 확정
